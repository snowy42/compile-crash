# As-built scope — alpha 0.1.0

## Implemented

The repository contains an executable browser game, not a collection of unconnected mockups. The run has 3 acts × (3 projects + 1 Trojan), 20 upgrade drafts, level 21 on full completion, final victory/crash outcomes, and banked permanent progression. All 48 modules, 36 patches, and 12 breakthrough definitions have engine handlers and rank fixtures. There are four rigs, six Trojans, eighteen named project presentations, twelve contract variants plus Standard, eight families and four-family seeded libraries.

The pipeline resolves ordered transforms, root-only triggers, stateful caches, worker schedules, copies, criticals, Guard, healing and explicit risk costs. The UI exposes exact card values, draft/replacement confirmations, ordering controls, batch thresholds, danger forecasts, archive, challenge/theme unlocks, and actual compile traces.

Permanent tracks are capped and refundable between runs. Settings include equivalent hold/tap, toggle and single-step input, rebindings, JS/VBA display, larger UI, quiet/reduced motion, contrast, volume and Assist. Practice clones a machine for a fixed 30-second reward-free benchmark. Saved games resume stopped.

IndexedDB implements atomic profile/run/reward snapshots, serialized generation-checked writes, a writer lease, recovery snapshots, export/import validation and explicit failure handling. Durable behavior is covered by the normal-origin browser suite; local environment limitations are documented separately.

## Not claimed complete

- Human fun/balance milestone, qualitative tester sessions, or a representative player win rate.
- A full screen-reader usability audit, physical-device Windows/Opera test, Firefox compatibility pass, or hardware performance guarantee.
- A comprehensive first-time-user curriculum; current guide is deliberately lightweight.
- Historical migration from non-existent older alpha schemas. Unknown versions are refused safely.
- Every combinatorial interaction exhaustively proven. Catalogue rank fixtures and selected exact regressions are a baseline, not exhaustive state-space coverage.

## Deliberately absent

No executable wrapper/installer, backend, cloud service, accounts, multiplayer, leaderboard, daily streak, endless mode, real editor/code execution, real malware behavior, mod scripting, online analytics, AI API calls, or paid dependency.

## Priority after the first play session

Record the seed and the specific confusing/boring/exciting moment. Fix that before expanding the content budget. The implementation's unit and seeded tests must continue to pass, and descriptions must continue to derive from the effect parameters.
