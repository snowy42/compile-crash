# Assets and dependencies

All in-game graphics are authored CSS, a small original SVG favicon, Canvas geometry, and inert text templates created for this project. Sounds are synthesized by the game's own bounded Web Audio oscillator code. The game uses system font stacks; no font files or remote fonts are included. No images, audio, dialogue, or code were copied from the games referenced by the design research.

TypeScript 5.8.3 is the sole npm development dependency, distributed under its own Apache-2.0 license. It is not a runtime browser dependency. Optional browser tests use Playwright 1.57.0 under its own license and downloaded test browsers. No application-code license is selected by this alpha; the repository owner can choose one separately.
