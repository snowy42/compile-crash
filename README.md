# COMPILE / CRASH

A keyboard-powered programming roguelite built around **progressive disclosure**.

The game begins with one idea: mash keys to make Work. Complexity is deliberately hidden until the player has learned the previous layer.

## Run it on Windows

1. Install Node.js 22+ if needed.
2. Clone this repository.
3. Double-click `PLAY.bat`.
4. The game opens at `http://localhost:5173`.

Or from a terminal:

```bash
git clone https://github.com/snowy42/compile-crash.git
cd compile-crash
npm run dev
```

## First-run progression

- Project 1: typing and Work only.
- Project 2: first three-choice upgrade draft.
- Project 4: Code Buffer + Compile introduced.
- Project 5: first pipeline module appears automatically.
- Project 6: second module slot and module drafts.
- Project 7: Integrity/security are revealed after an intrusion.
- Project 8: first easy Trojan encounter.
- Later projects: stronger Trojans and increasingly meaningful builds.
- First crash: Workshop and permanent Source Fragment progression unlock.

No rigs, challenge modes, collections, advanced build screens, or other vocabulary are shown before they are useful.
